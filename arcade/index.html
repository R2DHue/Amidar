Amidar — original arcade

This page emulates the 1982 Konami Amidar arcade board in your browser. No game ROM is included. Choose your own amidar.zip (MAME “amidar” set) or the individual ROM files. Files are checked by CRC32; renamed files (for example 8.11d/9.9d for the sound ROMs) are accepted.

The ROM stays on this device only: it is stored in this browser’s IndexedDB for this site so you don’t have to pick it again, and is never uploaded. “Forget saved ROM” deletes it. Controls: right joystick (4-way), left JUMP, COIN then 1P START. Keyboard: arrows/WASD, Space/X jump, 5/C coin, 1/Enter start, P pause. Controller: D-pad or left stick, A/B jump, View = coin, Menu = start.

Emulation core: JavaScript port of the Konami “Turtles/Amidar” board logic from MAME’s galaxian driver (BSD-3-Clause, Aaron Giles et al.), Z80 CPU by Molly Howell (MIT), ZIP by fflate (MIT). See LICENSES.txt.
